# Hivemind Cloud

We're the Cloud team of Agentic AI UW, a student org at UW Madison. We build and run the cloud side of Hivemind, the club's shared memory agent system: the model gateway, the agent runtime and the security that keeps each user's data separate.

Our code is private while we build. Learn more about the club at [agenticaiuw.com](https://agenticaiuw.com).
