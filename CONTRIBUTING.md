# Contributing to Hivemind Cloud

How we work, short version.

## Before you start

* Turn on two factor login for your GitHub account with an authenticator app, a passkey or a security key. The org won't let you in without it. Text message codes aren't allowed.
* Work in your own team's repo. Everyone in Cloud can read every repo. You can only push to your team's repo and the shared docs repo.

## Making a change

1. Make a branch off main with a short name, like `gateway-retry-logic`.
2. Keep commits small and clear.
3. Open a pull request that says what changed and how you tested it.
4. Someone from the team named in the repo's CODEOWNERS file reviews it. Don't merge your own pull request without a review.
5. Squash and merge. The branch deletes itself after.

## Never commit secrets

No API keys, tokens, passwords, private keys or .env files in any repo, ever. If you commit one by accident, tell the Security and Isolation team right away so we can rotate it. Deleting the commit isn't enough.

## AI tools

AI help is welcome. If you use GitHub Copilot, use Copilot Student (free for verified students) or turn off "Allow GitHub to use my data for AI model training" in your GitHub settings so club code stays out of training data. Never paste secrets or user data into any AI tool.

## Questions

Ask in your team's thread on Discord.
