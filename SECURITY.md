# Security

If you find a security problem in anything Hivemind Cloud builds or runs, please don't post it in an issue, a pull request or any public channel.

* **Club members:** message the Security and Isolation team or the Cloud lead directly on Discord.
* **Everyone else:** email team@agenticaiuw.com with what you found and how to reproduce it.

We'll confirm we got your report within 3 days and keep you updated while we fix it. Please give us time to fix the problem before you share it anywhere else.
