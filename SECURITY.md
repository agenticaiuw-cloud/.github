# Security

If you find a security problem in anything Hivemind Cloud builds or runs, please don't post it in an issue, a pull request or any public channel.

* **Club members:** DM Anand, the Cloud lead, on Discord. Don't post it in your team thread either. Review comments about a pull request's own changes are fine.
* **Everyone else:** email team@agenticaiuw.com with what you found and how to reproduce it.

We'll reply within 3 days and keep you updated. Please give us time to fix it before you share it anywhere else.
